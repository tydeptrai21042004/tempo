MANUSCRIPT EVIDENCE ADDITIONS
=============================

This release adds reporting and orchestration needed for the revised manuscript.
The watermarking method itself is unchanged except for diagnostic counters returned
by the existing bounded integer-closure kernel.

1. Native operating-point image benchmark
-----------------------------------------
python scripts/run_multiwatermark_metrics.py \
  --host-dir data/user_dataset/host \
  --watermark-dir data/user_dataset/watermark \
  --proposal-config configs/proposal_frozen.json \
  --out-dir results/native_image \
  --wm-size 64 \
  --attack-preset stress

New proposal columns include:
- integer_lattice_unit_updates
- integer_lattice_corrected_blocks
- integer_lattice_initial_parity_failures
- integer_lattice_initial_guard_failures
- integer_lattice_unresolved
- extraction_path, pilot_score, selected synchronization candidate, and shift
- fast-path and recovery-path timing summaries

2. Multi-host, multi-watermark matched-PSNR benchmark
-----------------------------------------------------
python scripts/run_multiwatermark_fair_benchmark.py \
  --host-dir data/user_dataset/host \
  --watermark-dir data/user_dataset/watermark \
  --proposal-config configs/proposal_frozen.json \
  --out-dir results/matched_psnr \
  --target-psnr 45.0 \
  --psnr-tolerance 0.75 \
  --attack-preset stress

The default method set is the four blind methods used in the primary comparison.
Add --methods with a comma-separated list to include semi-blind or informed methods.
Use --calibration-host-dir to provide an external held-out calibration set. When it
is omitted, deterministic synthetic held-out calibration hosts are generated.

Primary outputs:
- matched_psnr_by_host_watermark.csv
- matched_psnr_per_attack.csv
- matched_psnr_summary_by_method.csv
- matched_psnr_timing.csv
- matched_psnr_protocol.json

3. Real wall-clock stream experiment
------------------------------------
python scripts/live_stream_benchmark.py \
  --input path/to/real_video.mp4 \
  --watermark data/user_dataset/watermark/wm.png \
  --proposal-config configs/proposal_frozen.json \
  --workdir results/realtime_video \
  --methods proposal \
  --channels clean,jpeg70 \
  --resolutions 512x512,1280x720 \
  --target-fps 30 \
  --frames 300 \
  --wm-size 16 \
  --queue-size 2 \
  --pace-mode realtime

The stream summary now reports:
- on_time_completion_ratio over all generated frames
- p95 end-to-end latency deadline compliance
- sustained_realtime_end_to_end
- fast-path and recovery-path timing
- integer-closure diagnostics

Virtual mode now uses the same drop-oldest queue policy as realtime mode.

4. Encoded-video per-frame evidence
-----------------------------------
The existing extraction commands now create a per-frame CSV whenever a reference
watermark is supplied. The report contains per-frame bit accuracy, per-frame NC,
and running temporal-vote NC. The JSON summary adds the mean, minimum, p10, and the
number of frames needed to reach NC 0.90, 0.95, and exact recovery.

The field payload_bits_per_second remains the kernel-limited throughput for backward
compatibility. end_to_end_payload_bits_per_second is the end-to-end counterpart.
side_information_bytes_per_frame is explicitly labeled as amortized serialized
sequence-key metadata, not frame-dependent transmitted side information.

5. Multi-seed confidence intervals
----------------------------------
Run the selected benchmark once per seed in separate output directories, then use:

python scripts/aggregate_seed_results.py \
  --input-glob 'results/seed_*/matched_psnr_summary_by_method.csv' \
  --group-by method_id \
  --metrics mean_attack_nc,mean_evaluation_psnr,mean_total_embed_ms,mean_aligned_extract_ms,recovery_invocation_rate \
  --out results/multiseed_confidence_intervals.csv

The aggregator reports sample size, mean, sample standard deviation, and a 95-percent
bootstrap confidence interval for every requested metric.

6. Suggested manuscript tables generated by these outputs
----------------------------------------------------------
A. Matched-distortion comparison:
   matched_psnr_summary_by_method.csv
B. Integer-closure diagnostics:
   matched_psnr_by_host_watermark.csv or proposal ablation summary
C. Fast-path versus recovery-path timing:
   matched_psnr_per_attack.csv grouped by extraction_path and attack_category
D. Wall-clock real-time table:
   stream_realtime_summary.csv
E. Video per-frame and temporal-vote table:
   extraction report JSON and its corresponding *_per_frame.csv

7. Fully automated repeated-seed matched-PSNR run
-------------------------------------------------
python scripts/run_multiseed_matched_psnr.py \
  --host-dir data/user_dataset/host \
  --watermark-dir data/user_dataset/watermark \
  --proposal-config configs/proposal_frozen.json \
  --out-dir results/multiseed_matched_psnr \
  --seeds 2026,2127,2228,2329,2430 \
  --target-psnr 45.0 \
  --attack-preset stress

Each seed is written to its own seed_<value> directory. The final file
multiseed_confidence_intervals.csv contains the aggregated uncertainty report.
