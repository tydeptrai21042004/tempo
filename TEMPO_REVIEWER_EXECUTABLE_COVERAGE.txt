RUNTIME FIXES IN THIS PATCH
----------------------------------------------------------------------------
- Recovered all-black/all-white watermark is a measurable failed extraction,
  not an invalid *input* watermark. BER/NC and a constant-recovery flag are recorded.
- Real-video suite checks exact watermark-method pairs and can resume verified
  completed jobs independently; it rejects incomplete/duplicated checkpoints.
- Main pipeline KAGGLE_RESUME_FROM_VIDEO=1 preserves earlier image/ablation outputs.
- Completeness checker requires 720p clean and JPEG70 only for native HD streams,
  while all streams must have the 512x512 clean condition.
- Dataset preflight verifies 12 usable hosts and two non-degenerate 64x64 originals
  before long experiments, and leaves recovered watermarks unrestricted.
- Source integrity manifest updated with all changed/new files.
